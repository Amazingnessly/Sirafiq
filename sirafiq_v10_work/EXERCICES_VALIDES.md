# Exercices retenus pour Sirāfiq

## Mémorisation

- lecture fragmentée ;
- répétition guidée ;
- masquage progressif ;
- révélation ciblée ;
- restitution orale enregistrée ;
- réécoute et auto-évaluation ;
- vérification avec l’original ;
- révision quotidienne adaptative.

## Exercices explicitement exclus

- phrases ou textes à trous ;
- fragments à remettre dans l’ordre.

Ces deux formats ne doivent pas être réintroduits sans une demande explicite de l’utilisatrice.
