# Sirāfiq — Correctif fonctionnel v4

Ce lot cible uniquement les défauts fonctionnels validés avant la prochaine phase pédagogique.

## Corrigé

- lecteur PDF avec page précédente / suivante ;
- compteur de pages ;
- zoom avant / arrière ;
- geste horizontal pour changer de page ;
- ouverture du PDF dans le lecteur natif Safari en secours ;
- bouton « Supprimer la prise » avant conservation d’un nouvel audio ;
- bouton de suppression déjà présent sur chaque audio conservé ;
- bouton de suppression déjà présent sur chaque tracé conservé, rendu plus explicite ;
- cache PWA passé en v4 pour éviter de mélanger anciennes et nouvelles ressources.

## Important

Le lecteur multipage s’appuie sur PDF.js. Si cette bibliothèque ne peut pas être chargée, Sirāfiq propose automatiquement d’ouvrir le PDF dans le lecteur natif Safari.

Ce lot ne contient pas encore les parcours pédagogiques complets Écriture / Prononciation ni les mindmaps : ils seront développés après validation de ce correctif fonctionnel.
