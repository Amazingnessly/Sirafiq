# Sirāfiq v9

PWA personnelle, locale et hors compte pour iPhone/iPad.

## Ce que cette version cherche à faire

Sirāfiq ne doit plus seulement stocker des supports : il doit les transformer en actions de révision, suivre les auto-évaluations, préparer la prochaine reprise et proposer des espaces de pratique réellement utilisables.

### Mémoriser
- bibliothèque locale ;
- techniques : rappel libre, masquage progressif, questions, restitution orale/écrite, carte de mémoire ;
- suggestions selon la catégorie du support ;
- prochaine révision calculée à partir de l’état déclaré.

### Français oral / Prononcer
- progression sons → contrastes → rythme → enchaînements → lecture → explication → aisance ;
- modèle vocal français du système ;
- enregistrement local ;
- comparaison modèle / prise ;
- repères d’écoute sans faux score automatique.

### Écrire
- parcours Français et العربية ;
- gestes, familles, liaisons, mots, lignes, fluidité ;
- grand cahier multi-pages vertical et défilable ;
- mode Déplacer, stylo, surligneur, gomme, couleurs, épaisseurs, fonds ;
- enregistrement local et reprise d’un cahier.

### Cartes
- création manuelle ;
- création depuis le texte fourni ;
- déplacement, ajout, suppression, zoom et dispositions ;
- correctif de compatibilité pour Safari plus ancien.

### Boussole Sirāfiq
Moteur local et explicable fondé sur les états de maîtrise et l’activité enregistrée. Il ne prétend pas être un modèle d’IA distant ni établir un diagnostic qu’il ne peut pas mesurer.
