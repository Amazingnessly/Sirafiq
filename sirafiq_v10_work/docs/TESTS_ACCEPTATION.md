# Tests d’acceptation

## Règle

Un lot n’est validé qu’après test sur Safari iPad et, lorsque disponible, Safari iPhone. Les tests doivent être exécutés depuis l’URL GitHub Pages et depuis l’icône installée sur l’écran d’accueil.

## Import

- [ ] Importer un fichier texte UTF-8.
- [ ] Importer une image depuis Photos.
- [ ] Importer un PDF depuis Fichiers.
- [ ] Importer un audio de référence.
- [ ] Refuser proprement un format non pris en charge.
- [ ] Afficher la taille du fichier.
- [ ] Prévisualiser avant validation.
- [ ] Fermer l’application puis retrouver le support.
- [ ] Supprimer uniquement après confirmation.

## Audio

- [ ] Expliquer la demande de microphone avant l’ouverture système.
- [ ] Gérer l’autorisation accordée.
- [ ] Gérer l’autorisation refusée avec instructions claires.
- [ ] Enregistrer au moins 60 secondes.
- [ ] Mettre en pause puis reprendre.
- [ ] Arrêter et réécouter.
- [ ] Fermer puis retrouver le vocal.
- [ ] Renommer, noter et mettre en favori.
- [ ] Comparer deux vocaux par écoute alternée.
- [ ] Confirmer toute suppression.
- [ ] Ne jamais supprimer automatiquement un vocal.

## Séance et révision

- [ ] Préparer une séance comportant une révision prioritaire.
- [ ] Afficher la raison de chaque activité.
- [ ] Interrompre puis reprendre exactement au même endroit.
- [ ] Enregistrer le nombre de révélations.
- [ ] Enregistrer l’auto-évaluation.
- [ ] Recalculer la prochaine révision.
- [ ] Permettre une modification manuelle de l’état de maîtrise.

## Mindmaps

- [ ] Créer une carte manuelle.
- [ ] Créer une carte depuis un texte.
- [ ] Créer une carte depuis une sélection.
- [ ] Afficher l’extrait source exact d’un nœud.
- [ ] Modifier et valider un libellé.
- [ ] Replier et déployer une branche.
- [ ] Zoomer par pincement.
- [ ] Déplacer la carte au doigt.
- [ ] Utiliser le mode focus.
- [ ] Fermer puis retrouver la disposition.
- [ ] Lancer un exercice depuis une branche.
- [ ] Associer et réécouter un vocal.

## Coran

- [ ] Importer un texte arabe fourni par l’utilisateur sans altération.
- [ ] Vérifier caractère par caractère après restauration.
- [ ] Interdire la correction silencieuse.
- [ ] Ne générer aucun résumé, thème, traduction ou commentaire.
- [ ] Autoriser uniquement une segmentation neutre ou des titres utilisateur.

## Écriture

- [ ] Tracer au doigt.
- [ ] Tracer avec un stylet tiers.
- [ ] Annuler le dernier trait.
- [ ] Effacer après confirmation lorsque nécessaire.
- [ ] Rejouer la démonstration animée.
- [ ] Respecter les proportions et le ductus validés.

## Sauvegarde

- [ ] Exporter sans fichiers binaires.
- [ ] Exporter avec supports et vocaux.
- [ ] Afficher la taille estimée.
- [ ] Restaurer dans une base vide.
- [ ] Détecter les doublons.
- [ ] Ne pas écraser sans confirmation.
- [ ] Vérifier les textes, cartes, positions, tentatives et vocaux après restauration.
